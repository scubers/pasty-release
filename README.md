# Clipbus

> The programmable clipboard manager for macOS.

Clipbus is a keyboard-first clipboard manager for macOS you can extend with Node.js plugins — write detectors that react to what you copy (JWT, Base64, JSON, color hex…), render rich inline cards, and expose ⌘K actions, all without leaving the keyboard. Built on a native C++17 core — no Electron, no subscription.

**This repository hosts the official macOS release artifacts** (DMG / zip) and the Sparkle update feed. For the product itself, see **[clipbus.com](https://clipbus.com)**.

## Download

- **Direct download (DMG):** [Clipbus.dmg](https://github.com/scubers/clipbus-release/releases/latest/download/Clipbus.dmg)
- **Homebrew:** `brew install scubers/tap/clipbus`
- **Website:** [clipbus.com](https://clipbus.com)

Requires **macOS 15+** (Apple Silicon).

## About this repository

- **Releases** — each tagged release attaches the macOS `Clipbus.dmg` and `.zip` build artifacts.
- **Auto-update** — the DMG build updates itself via [Sparkle](https://sparkle-project.org/); the appcast feed is published on the `gh-pages` branch. Only `gh-pages` is generated by the release pipeline — everything on `main` is hand-maintained.
